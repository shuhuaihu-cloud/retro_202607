# Design Principles

Less is more.

Large whitespace.

Editorial layout.

Architecture first.

Photography first.

Typography second.

Decoration last.

Every page should have one dominant visual focus.

Avoid information overload.

Never imitate PowerPoint.

# Typography (字型排版規範)

Primary (主要無襯線體，適用於標題、導覽、數據)

`Inter`, `"PingFang TC"`, `"Heiti TC"`, `"Noto Sans TC"`, `"Microsoft JhengHei"`, sans-serif

Secondary (主要襯線體，適用於故事內文、大字引言)

`"Source Serif 4"`, `"Noto Serif TC"`, `"Songti TC"`, `"PMingLiU"`, serif

Fallback

serif

Rules

* Large titles (大標題，氣勢磅礡且呼吸空間充足)
* Small paragraphs (內文段落精簡，字級適中)
* High line spacing (高行距，中文建議 `1.6` 至 `1.8` 以保持高閱讀舒適度)
* Large margins (大邊距，留下大量空白)
* Editorial hierarchy (如雜誌般的編輯排版階層)

# Layout Rules

Prefer

2-column layouts (兩欄式非對稱排版)

Asymmetry (不對稱美學)

Large image blocks (大區塊圖片)

Full-width photography (滿版跨頁攝影)

Large captions (清晰且大字級的圖說)

Never center every element. (避免所有元素居中對齊，善用不對稱排版)

Leave breathing room. (留出充足的呼吸與留白空間)
