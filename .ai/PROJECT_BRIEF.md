# Presentation Topic

Shanghai Modern Residential Architecture (上海近代住宅建築)

Case Studies

1. Sun Ke Villa (孫科別墅)
2. Rong Zhai (榮宅)
3. Wu Tongwen Residence / Green House (吳同文住宅 / 綠房子)

The narrative is not "three buildings."

The narrative is:

**How Shanghai elite residential architecture evolved from Beaux-Arts and Eclectic traditions toward Modernism during the Republican era.**
**(上海精英住宅建築在民國時期如何從折衷主義與美式新古典傳統，逐步演變並走向現代主義。)**

Every page should support this story.

---

# Language Requirement (語言規範)

All user-facing content (including copy, titles, captions, navigation, UI elements, labels, comparisons, and charts) must be written in **Traditional Chinese (繁體中文)**.

The presentation should read naturally, using professional architectural and historical terminology in Traditional Chinese.
